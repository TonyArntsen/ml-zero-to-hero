# A* Search

A* is a pathfinding and graph-search algorithm that expands the most promising node according to a cost estimate, combining the actual cost so far with a heuristic estimate of the remaining distance.

## Good sources to look up
- Artificial Intelligence: A Modern Approach by Russell and Norvig
- "A* Search Algorithm" notes and tutorials from university CS courses
- The original A* paper by Hart, Nilsson, and Raphael
- Wikipedia and algorithm visualizations for admissible and consistent heuristics

## Handy math concepts
- Graph theory and weighted graphs
- Priority queues and heap-based ordering
- Heuristic functions and admissibility
- Cost-to-come vs cost-to-go
- Big-O time and memory analysis
- Shortest-path reasoning and dynamic programming intuition

## Typical things to practice
- Manhattan distance and Euclidean heuristics
- Closed set vs open set behavior
- Why admissible heuristics keep A* optimal
- Comparing A* with Dijkstra and BFS on the same graph
