# K-Nearest Neighbors

K-nearest neighbors is a simple instance-based learning method: classify or regress based on the nearest labeled examples in feature space.

## Good sources to look up
- The Elements of Statistical Learning by Hastie, Tibshirani, and Friedman
- Pattern Recognition and Machine Learning by Bishop
- scikit-learn documentation for KNeighborsClassifier and KNeighborsRegressor
- Introductory ML notes on distance metrics and nearest-neighbor methods

## Handy math concepts
- Distance metrics: Euclidean, Manhattan, Minkowski
- Vector geometry and feature spaces
- Probability and decision boundaries
- Bias-variance trade-off
- Normalization and scaling
- Curse of dimensionality

## Typical things to practice
- Choosing k and understanding underfitting vs overfitting
- Standardizing features before distance computation
- Comparing Euclidean and cosine distance
- Cross-validation for model selection
- Building a small neighbor-based classifier from scratch
