# Q-Learning

Q-learning is a model-free reinforcement learning method that estimates the value of taking an action in a state and learns an optimal policy through repeated interaction with an environment.

## Good sources to look up
- Reinforcement Learning: An Introduction by Sutton and Barto
- David Silver's RL lectures and notes
- OpenAI Spinning Up reinforcement learning guides
- Introductory RL tutorials on tabular Q-learning and environments

## Handy math concepts
- Markov decision processes (MDPs)
- Bellman equations and dynamic programming
- Probability and expectation
- Value functions and policy evaluation
- Discount factors and reward signals
- Exploration vs exploitation

## Typical things to practice
- Tabular Q-table updates and state-action values
- Epsilon-greedy exploration
- Discount factors and reward shaping
- Comparing Q-learning to dynamic programming and SARSA
- Training on simple grid-world and classic control tasks
