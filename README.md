# ML Zero to Hero

A small self-study roadmap from classic algorithms to modern neural networks and transformer models.

## Learning path

- `algdat-basic` — core algorithms, data structures, and complexity
- `a-star` — pathfinding and heuristic search
- `q-learning` — reinforcement learning basics
- `genetic-algorithms` — evolutionary optimization
- `neat-implementation` — neuroevolution
- `k-nearest-neighbor` — classic supervised learning
- `dense-neural-networks` — feedforward networks and backpropagation
- `autograd-engine` — autodiff from scratch
- `convolutional-neural-networks` — CNNs for vision
- `recurrent-neural-networks` — sequence models and RNNs
- `tree-based-models` — decision trees and ensembles
- `single-head-casual-self-attention` — transformer attention basics
- `micro-gpt` — tiny GPT-style model
