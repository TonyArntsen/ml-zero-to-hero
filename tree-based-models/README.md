# Tree-Based Models

Tree-based models split feature space into regions using rules learned from data. Common examples include decision trees, random forests, and gradient-boosted trees.

## Good sources to look up
- The Elements of Statistical Learning by Hastie, Tibshirani, and Friedman
- scikit-learn documentation for tree ensembles
- XGBoost, LightGBM, and CatBoost tutorials and docs
- Introductory ML notes on decision trees and boosting

## Handy math concepts
- Information theory: entropy and information gain
- Probability and impurity measures
- Splitting criteria and threshold optimization
- Bias-variance trade-off
- Linear algebra is useful for feature handling, but trees are mostly rule-based
- Convex optimization intuition for boosting methods

## Typical things to practice
- Building a decision tree from scratch
- Gini impurity vs entropy vs classification error
- Feature importance and pruning
- Random forests and ensemble variance reduction
- Gradient boosting and shallow tree ensembles on tabular data
