# Dense Neural Networks

Dense neural networks, also called fully connected networks, stack layers of linear transformations and nonlinear activations to learn mappings from inputs to outputs.

## Good sources to look up
- 3Blue1Brown's neural networks and backpropagation videos
- Stanford CS231n notes on neural networks
- Deep Learning by Goodfellow et al.
- Andrew Ng's machine learning and deep learning courses

## Handy math concepts
- Linear algebra: dot products, matrices, and vector spaces
- Calculus and gradients
- Chain rule and backpropagation
- Optimization: gradient descent, momentum, and learning rate
- Probability and classification losses
- Activation functions and nonlinearity

## Typical things to practice
- Feedforward pass and parameter counts
- ReLU, sigmoid, tanh, and softmax behavior
- Loss functions such as cross-entropy and MSE
- Training on tabular data and small classification tasks
- Diagnosing underfitting, overfitting, and vanishing gradients
