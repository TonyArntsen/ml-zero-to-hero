# Micro GPT

A micro GPT project usually means implementing a compact transformer-based language model, including tokenization, embeddings, attention, and next-token prediction in a minimal form.

## Good sources to look up
- The original Attention Is All You Need paper
- OpenAI's GPT papers and model cards
- Andrej Karpathy's makemore and llm.c tutorials
- Minimal GPT implementations and transformer reference code

## Handy math concepts
- Probability and discrete distributions
- Softmax and cross-entropy
- Embeddings and positional encodings
- Matrix multiplication and attention scores
- Differentiation and backpropagation through transformer blocks
- Numerical stability and scaling tricks

## Typical things to practice
- Building token embeddings and position embeddings
- Implementing causal self-attention and masking
- Training on small text corpora
- Reading logits and next-token prediction mechanics
- Understanding context windows and transformer depth
