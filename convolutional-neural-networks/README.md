# Convolutional Neural Networks

CNNs are designed for grid-like data such as images and sequences, using local filters and shared weights to capture spatial patterns efficiently.

## Good sources to look up
- CS231n: Convolutional Neural Networks for Visual Recognition
- Deep Learning by Goodfellow, Bengio, and Courville
- Andrew Ng's deep learning notes on CNNs
- Papers on LeNet, AlexNet, VGG, ResNet, and modern vision architectures

## Handy math concepts
- Linear algebra: vectors, matrices, tensors
- Discrete convolution and cross-correlation
- Signal processing intuition for filters and kernels
- Calculus and backpropagation through convolutional layers
- Probability and optimization for training
- Feature maps and receptive fields

## Typical things to practice
- Stride, padding, and kernel size effects
- Feature extraction hierarchies across layers
- Pooling and invariance to small shifts
- Training a small CNN on image data
- Reading activation shapes through each layer
