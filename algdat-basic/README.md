# Algorithms and Data Structures Basics

This folder is a baseline for the core ideas behind efficient computation: how data is stored, how algorithms scale, and how to reason about complexity.

## Good sources to look up
- Introduction to Algorithms by Cormen, Leiserson, Rivest, and Stein
- Algorithms by Sedgewick and Wayne
- MIT OpenCourseWare 6.006: Introduction to Algorithms
- "Big O" and asymptotic analysis notes from classical CS curricula

## Handy math concepts
- Asymptotic notation: O, Omega, Theta
- Recurrence relations and master theorem
- Proof by induction
- Basic combinatorics and counting
- Graph basics: nodes, edges, connectivity, traversal
- Probability fundamentals for randomized algorithms

## Typical things to practice
- Arrays, stacks, queues, hash tables, trees, and heaps
- Sorting and searching fundamentals
- Graph traversal with DFS and BFS
- Complexity trade-offs for time and memory
- Algorithm design patterns and correctness reasoning
